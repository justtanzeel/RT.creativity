# RT Designer — Portfolio

Professional creative design portfolio by **Tanzeel ur Rehman (RT Designer)**, Rawalpindi, Pakistan.

## 🚀 Live on GitHub Pages

This portfolio is ready to deploy on **GitHub Pages** for free.

### How to deploy:

1. Create a new repository on GitHub (e.g. `rt-designer-portfolio`)
2. Upload all these files **keeping the folder structure exactly as is**
3. Go to your repo → **Settings** → **Pages**
4. Under **Source**, select `main` branch → `/ (root)` → click **Save**
5. Your portfolio will be live at: `https://yourusername.github.io/rt-designer-portfolio`
